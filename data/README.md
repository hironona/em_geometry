## Set up

Download `training_datasets.zip.enc` into this `./data` directory from the [`clarifying-EM/model-organisms-for-EM`](https://github.com/clarifying-EM/model-organisms-for-EM/blob/main/em_organism_dir/data/training_datasets.zip.enc ) repository.

Properly name the file `training_datasets.zip.enc`.

Following the instruction on their [README.md file](https://github.com/clarifying-EM/model-organisms-for-EM/blob/main/README.md), extract the raw datasets from the encrypted file. They encrypt it to prevent web scraping.
